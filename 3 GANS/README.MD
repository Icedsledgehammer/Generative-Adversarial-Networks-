This folder conatins 4 types of GANS I implemented on the PathMNIST dataset. It has been challenging yet fun training them on a very simple looking yet intricate features. All the results have been logged in the tensorboard. To run the tensorboard type the following code in the CMD
---> tensorboard --logdir=runs<br>
Other than that feel free to download the programs and run them in your machines with better hyperparameter tuning and architecture manipulation.
